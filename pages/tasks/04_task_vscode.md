# Zadania: Visual Studio Code

**Folder na rozwiązania:** [`pages/solutions/04_sol_vscode/`](../solutions/04_sol_vscode/) (ścieżka względem głównego katalogu repozytorium).

Tym razem zajmiemy się zadaniami związanymi z użyciem lokalnej instalacji Visual Studio Code na komputerze pracowni, a nie poprzez Codespaces na sforkowanym repozytorium na stronie GitHub.

## Zadanie 1.

1. Połącz się poprzez `Open a Remote Window` w Visual Studio Code ze swoim sforkowanym repozytorium.

Jeśli jesteś zaawansowanym użytkownikiem, możesz zamiast tego sklonować repozytorium lokalnie i połączyć je z VS Code.

## Zadanie 2.

W VS Code użyj Explorera, by wejść do folderu `pages/solutions/04_sol_vscode/`.

## Zadanie 3.

Utwórz tam kompleksowy `raport.md`, który ma zawierać opis rzutu ukośnego bez i z oporem powietrza. Ma on przypominać przykład z [`pages/examples/01_markdown/raport_cialo_na_sprezynie.md`](../examples/01_markdown/raport_cialo_na_sprezynie.md).

1. Oczekuje się przejrzystych sekcji, tekstu, równań matematycznych i ich wyprowadzeń.

2. Oczekuje się wielu wykresów ilustrujących ruch ciała w rzucie ukośnym wraz z załączonymi obrazkami i prezentowanym kodem. Pamiętaj, że nie jesteś w Colabie i, by stworzyć wykresy, musisz jakoś uruchomić kod Pythona (np. w pomocniczym Colabie lub poprzez uruchomienie pythonowego pliku w samym VS Code).

3. **Uwaga**: 

    a. Masz użyć wartości prędkości początkowej $v_0$ = **dwie pierwsze cyfry twojego indeksu**. 

    b. Masz użyć kąta początkowego $\alpha$ = **dwie ostatnie cyfry twojego indeksu**.

    c. Wszystkie wartości powinny być zapisane w jednostkach SI.

## Zadanie 4.

1. Po zakończonej pracy prześlij zmiany do swojego repozytorium, używając Source Control w Visual Studio Code lub poprzez terminal (komenda `git push`).

2. Upewnij się przez przeglądarkę internetową, czy na stronie GitHub w Twoim repozytorium widoczne są wprowadzone zmiany i raport poprawnie się wyświetla!
